### Changed

- **FEAT-005** (fix): The link checker computed the anchor of a heading with inline code without the code text, so it rejected `#the-current-mapping-for-unknown`, which GitHub accepts. It now keeps that text, and a test covers it. Validated: `python3 -m unittest discover -s tools -p test_check_docs.py`. Docs: updated tools/check_docs.py, tools/test_check_docs.py.
- **TASK-016** (fix): Harden reconciliation and test the reliability claims. An empty lookup is believed only when the capability declares absence final and the settle window has passed; an open unknown holds its resource against a retry under a new key; clients are told never to retry an unknown. Invariants are separated from policies, the needs of more than one replica are listed, and the contract carries optional governance declarations. The reference gains a fault-injection and concurrency suite and a durable SQLite journal. Ref: docs/pattern.md#reliability-rule-the-journal. Validated: `python3 tools/check_docs.py . && cd reference/python && pytest -q`. Docs: updated README.md, docs/pattern.md, docs/index.md, docs/decision-guide.md, docs/example.md, docs/protocol-mapping.md, reference/README.md, reference/abstraction.md, launch/article.md, launch/hashnode.md.
- **TASK-015** (fix): Separate what is known about an action from what to do next. `deferred` is replaced by `unknown`, a fallback channel is offered only when the action is known not to have been done, a timeout is settled like a crash, and unresolved outcomes go to the named owner. Three delivery classes and the operation id are defined. Ref: docs/pattern.md#what-the-journal-guarantees-and-what-it-does-not. Validated: `python3 tools/check_docs.py . && cd reference/python && pytest -q`. Docs: updated README.md, docs/pattern.md, docs/index.md, docs/decision-guide.md, docs/example.md, docs/protocol-mapping.md, docs/influences.md, docs/diagrams/recovery.svg, reference/README.md, reference/abstraction.md, launch/article.md, launch/hashnode.md.
